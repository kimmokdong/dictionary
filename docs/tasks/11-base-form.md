# 작업 지시 11 — 기본형 탐정 (세 번째 놀이)

`기획서_v2.md` 6-0절(놀이 공통)과 6-2b절(기본형 탐정)을 읽는다. 놀이 두 개(`src/quickfind.js`, `src/openonce.js`)와 놀이 고르기(`src/games.js`)가 이미 동작한다. 같은 틀에 세 번째 놀이를 더한다.

## 놀이 규칙
- 문장 속 굵은 활용형(예: "동생이 발끝을 **돋워** 창밖을 봤다.")의 기본형을 사전에서 찾아 그 표제어를 터치한다.
- 한 판 5문제, 시간 제한 없음. 문제마다 책은 첫 펼침(맨 앞)에서 시작한다. 넘김·색인·옆면은 평소 그대로 쓴다.
- 낱말 터치 판정(빨리 찾기와 같은 짧은 터치 규칙):
  - 정답 표제어(`id`가 같음): 그 항목을 표시하고 "찾았어요! 돋워 → 돋우다"와 그 문제의 `tip` 풀이를 쪽지에 보여 준다. 풀이를 읽을 수 있게 자동으로 넘어가지 않고 **다음 문제** 버튼을 둔다.
  - 같은 기본형의 다른 동음이의어(`w`는 같고 `id`가 다름): "기본형은 맞았어요! 그런데 뜻이 다른 '묻다'예요. 바로 옆의 '묻다'도 살펴봐요." 오답 횟수 +1.
  - 그 밖: 지금처럼 `isIt(w)`("이건 '○○'예요"), 오답 횟수 +1. 멈추지 않는다.
- 힌트 버튼(카드 안): 누를 때마다 한 단계씩.
  1. "'-다'로 끝나는 모양으로 바꿔 봐요."
  2. "첫 글자는 '돋'이에요." (기본형 첫 글자)
  3. 기본형이 있는 색인 탭 반짝(빨리 찾기 30초 힌트와 같은 표시).
  4. 세 힌트를 다 쓴 뒤에는 버튼이 **정답 보기**로 바뀐다. 누르면 정답 펼침을 열고 항목 표시와 풀이를 보여 준다(그 문제 0점).
- 점수: 문제마다 3점에서 쓴 힌트 수만큼 뺀다(최소 1점, 정답 보기는 0점). 한 판 15점. 오답 터치는 점수에서 빼지 않는다(여러 낱말을 눌러 보는 것을 막지 않기 위해). 기록에는 문제별 힌트 수·오답 수·넘긴 횟수를 남긴다.

## 화면
- 놀이 고르기에 **기본형 탐정** 추가 → 세트 고르기(쉬움 1~3, 보통 4~6, 어려움 7~9, 세트마다 이 기기 최고 점수).
- 띠 가운데 카드: 문장 한 줄(활용형만 굵게, 글자는 `textContent`/이스케이프로 넣는다), 문제 번호(2/5), 힌트 버튼. 문장이 길면 카드 폭 안에서 줄바꿈하거나 글자를 조금 줄여 띠 높이를 넘지 않게 한다. 힌트 1·2 문구는 카드 아래 줄(빨리 찾기의 길잡이 힌트 자리)에 보인다.
- 결과 판(다른 놀이와 같은 크기·위치): 문제별 표(활용형 → 기본형, 힌트, 오답), 총점/15, 과정 위주 칭찬 한두 줄(예: 힌트 없이 찾은 문제 수, "모양이 바뀌는 낱말을 끝까지 추적했어요"). 버튼: 다시 하기, 다른 세트, 사전으로. 최고 점수 `localStorage`(`dictionary-baseform-v1`), 새 기록이면 "새 기록!".
- 놀이 중 글씨 크기 버튼 막기, "놀이" 버튼은 "그만하기"(다른 놀이와 같음).

## 데이터
- `data/games/base-form.json`(이미 작성됨, **읽기만**): 세트 9개×5문제. 문제 = `{ before, form, after, w, id, tip }`. 문장 = `before + form + after`, `form`이 굵게 보일 활용형, `w`·`id`가 정답 표제어.
- `npm run build:data`가 다른 놀이처럼 `linkGame`으로 `seq`를 붙여 `data/build/games/base-form.json`을 만든다. 찾지 못한 ID나 표기가 다르면 빌드 실패. `data/build/README.md`에 추가.

## 구조
- 새 모듈 `src/baseform.js`, `src/games.js`에 등록. `main.js`는 바꿀 필요가 없으면 건드리지 않는다(지금의 "진행 중인 놀이" 연결로 충분해야 한다).
- DOM과 무관한 것(점수 계산, 힌트 단계 문구, 판정 분류: 정답/동음이의어/그 밖, 기록 저장 형식·손상값 복구, 칭찬 문구)은 내보내고 `tests/`에 테스트.
- `?debug`에서 `window.__baseForm`(상태, 정답 펼치기) 시험 도구.
