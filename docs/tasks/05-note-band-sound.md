# 작업 지시 05 — 쪽지 내용 교체, 위쪽 도구 띠, 넘기는 소리

전체 기획은 `기획서_v2.md`, 직전 작업은 `docs/tasks/04-word.md`를 읽는다. 책 넘김·낱말 터치·글씨 크기 전환은 이미 동작한다. 이 작업은 사용자가 써 보고 요청한 세 가지를 고친다.

## 현재 구조

- 앱: `index.html`, `src/style.css`, `src/main.js`, `src/word.js`, `src/geometry.js`. 1366×768 무대(`#stage`)를 화면에 맞춰 통째로 확대·축소한다(`fit()`, 입력 좌표는 `pt()`).
- 데이터 빌드: `npm run build:data` → `scripts/data/build.mjs`가 `select.mjs`(원자료 선별), `typeset.mjs`(조판)를 써서 `data/build/`를 만든다. 원자료는 `data/raw/krdict/extracted/*.json`(한국어기초사전, 이미 풀려 있음).
- 쪽지는 지금 `data/build/entries/entries-NNNN.json`을 읽어 `word.js`의 `entryHtml`로 그린다.

## 1. 쪽지 내용: 지면에 없는 정보만

지금 쪽지는 지면의 뜻풀이를 글씨만 키워 되풀이한다. **뜻풀이는 빼고**, 지면에 싣지 못한 정보를 보여 준다. 뜻은 지면에서 읽는다(선택한 항목은 지면에 표시된다).

### 쪽지에 넣을 것 (원자료에 있는 것만, 고쳐 쓰지 않는다)
- 표제어(어깨번호), 품사, 권장 학년군 — 지금과 같다.
- **발음**: `WordForm` type `발음`의 표기(예: 돋우다 [도두다]). 표제어와 같으면 생략해도 된다.
- **활용**: `WordForm` type `활용`의 형태(예: 돋우어(돋워), 돋우니). 최대 4개.
- **한자 원어**: 항목의 `origin`이 있으면 표시(예: 徒步).
- **뜻별 예문**: 뜻 번호(지면의 ①② 와 같은 번호)마다 `SenseExample` type `문장` 최대 2개, type `대화` 최대 1개. 지면에 이미 실은 예문과 같은 문장은 뺀다. 대화는 원문의 한 줄 한 줄(가/나 화자)을 줄을 나눠 보여 준다.
- **관용구·속담**: 이 항목과 같은 기초사전 ID를 가진 `lexicalUnit`이 `관용구`/`속담`인 항목들. 표현과 첫 번째 뜻풀이(이건 지면에 없으므로 뜻풀이를 보여 준다). 최대 5개.
- **파생어**: `RelatedForm` type `파생어`의 표기. 최대 5개.
- 비슷한말·반대말은 지면에 이미 있으므로 쪽지에서는 뺀다.
- 위 정보가 하나도 없는 낱말이면 "이 낱말은 지면에 실린 내용이 전부예요." 한 줄을 보여 준다.

### 데이터
- 쪽지 정보는 **별도 파일**로 만든다: `data/build/notes/notes-NNNN.json`(표제어 순번 `seq` 기준 500개씩, `entries`와 같은 묶음 규칙). 조판 입력(`entries`)에는 넣지 않는다.
- `scripts/data/`를 고쳐 `npm run build:data` 한 번으로 함께 나오게 한다. 관용구·속담은 지금 `select.mjs`에서 버리고 있으니, 수록된 항목의 ID에 붙는 것만 모은다.
- **지면 결과가 바뀌면 안 된다**: 빌드 전후로 `data/build/normal|large|xlarge/` 전체와 `data/build/entries/`의 파일 내용이 바이트 단위로 같아야 한다(해시로 비교해 확인).
- `data/build/README.md`에 notes 스키마를, `ATTRIBUTION.md`의 가공 내용에 "쪽지용 발음·활용·예문·관용구·속담·파생어를 원문 그대로 추가 수록"을 한 줄 더한다(빌드 스크립트가 만드는 파일이면 스크립트에서).
- `data/build/report/summary.json`에 notes 통계(정보가 있는 항목 수, 전체 용량)를 넣는다.

## 2. 위쪽 도구 띠

책이 화면을 꽉 채워 버튼 둘 자리가 없다. **책 위에 높이 56px 띠**를 두고, 책갈피 버튼(`#ribbon`)과 그 드롭다운 메뉴는 없앤다.

- 화면 맞춤의 기준을 1366×(56+768)로 바꾼다. 책 무대(`#stage`, 1366×768)는 띠 아래에 그대로 두고 `src/geometry.js`의 좌표·상수는 **바꾸지 않는다**. 입력 좌표 변환(`pt()`)만 띠 높이를 반영한다.
- 띠 구성: 왼쪽에 "국어사전" 제목. 오른쪽에 버튼들 — 글씨 크기(보통/크게/아주 크게, 지금 단계가 눌린 상태로 보이는 3개 버튼), 소리 켜기·끄기, 전체 화면 켜기·끄기, "이 사전에 대하여"(누르면 띠 아래로 작은 패널, 지금 메뉴의 출처 문구를 그대로 옮김, 밖을 터치하면 닫힘).
- 버튼 높이 44px 이상(태블릿 터치). 책·책상 분위기와 어울리는 차분한 색. 아이콘이 필요하면 인라인 SVG나 글자로, 외부 아이콘 라이브러리 금지.
- 다음 단계에서 "낱말 빨리 찾기" 버튼이 하나 더 들어갈 자리를 비워 둔다(지금은 버튼을 만들지 않는다).
- 넘기는 도중에는 띠 버튼을 받지 않는다(지금 메뉴와 같은 규칙).

## 3. 넘기는 소리

- **소리 파일 없이** Web Audio API로 종이 스치는 소리를 합성한다. 새 모듈 `src/sound.js`.
- 한 장: 넘기기 시작할 때 짧고 가벼운 스침(대역 통과 필터를 건 잡음, 빠른 감쇠), 종이가 내려앉을 때 부드러운 "탁".
- 묶음(여러 장): 더 길고 낮은 스침에 넘기는 장수에 비례한 짧은 따닥임(최대 10회 정도)을 섞는다.
- 넘기다 되돌아가는 경우도 내려앉을 때 소리를 낸다. 색인 탭·옆면을 잡기만 하고 놓으면 소리 없음.
- 음량은 작게(교실에서 여러 대가 동시에 켜도 시끄럽지 않게). 기본값은 켜짐, `localStorage`에 저장.
- `AudioContext`는 첫 사용자 터치 때 만든다(자동 재생 제한). 소리를 못 내는 환경이면 조용히 넘어간다(오류 없음).

## 지켜야 할 것

- 넘김 동작(한 장, 묶음, 색인, 스냅, 휘어짐, 그림자)의 모양과 판정, 낱말 터치 판정을 바꾸지 않는다. `src/geometry.js`는 그대로 둔다.
- 쪽지 위치·크기·닫힘 규칙(반대쪽 면 위, 폭 500, 최대 620 스크롤, 밖 터치·넘김 시작 시 닫힘)은 지금대로 둔다.
- 프레임워크, 번들러, 새 의존성 추가 금지.
- `기획서_v2.md`, `docs/`, `data/raw/`는 수정하지 않는다.
- 원자료 문장을 고쳐 쓰지 않는다.
- 코드 주석은 한국어, 기존 방식(짧은 함수, 한 줄 이유 주석).
- 확인용 스크린샷·임시 파일은 프로젝트 폴더에 남기지 않는다(지난번 `output/playwright/`는 지워도 된다).
- **작업이 끝나면 직접 띄운 브라우저, 서버, 백그라운드 프로세스를 모두 종료하고 끝낸다.**
- git 커밋 금지.

## 완료 조건

- `npm run build:data` 성공, 지면·entries 파일이 빌드 전과 바이트 단위로 같음(확인 방법과 결과를 보고).
- `npm test` 통과(기존 17개 유지). notes 생성 로직(예문 중복 제거, 개수 제한, 관용구 연결)에 테스트를 추가한다.
- 브라우저에서 확인:
  1. "돋우다", "눈", "가다"처럼 정보가 많은 낱말과 정보가 거의 없는 낱말을 각각 터치해 쪽지 내용이 규칙대로 나온다.
  2. 위쪽 띠가 보이고 책이 그 아래에 비율 그대로 들어간다. 넘김·색인·옆면·낱말 터치 위치가 손가락과 어긋나지 않는다.
  3. 띠의 글씨 크기·소리·전체 화면·이 사전에 대하여가 동작하고, 새로 고침해도 글씨 크기·소리 설정이 유지된다.
  4. 한 장/묶음 넘김에서 소리 함수가 규칙대로 불린다(소리 자체는 들을 수 없으면 호출 기록으로 확인).
- 콘솔 오류가 없다.
