# 작업 지시 13 — 화면 꾸미기: "책상 위 사전"

`docs/design/mockup-1-desk.png`(시안, 사용자가 고름)를 먼저 본다. 비교용 지금 화면은 `docs/design/current-panel.jpg`, `current-note.jpg`. 시안처럼 **나무 책상 위에 놓인 가죽 표지 사전** 느낌으로 사전 주변 꾸밈을 바꾼다. 시안은 분위기 참고용이며 픽셀 그대로 따라 할 필요는 없다.

## 바꾸는 것
1. **바탕**: 책 바깥(화면 여백 포함)을 따뜻한 나무 책상 결로. 이미지 파일 없이 CSS 그라디언트로 만든다(가는 나뭇결 줄무늬와 은은한 밝기 차).
2. **표지(`#cover`)**: 짙은 갈색 가죽 질감과 가장자리 박음질(점선) 테두리, 살짝 둥근 모서리와 그림자.
3. **위쪽 띠(`#band`, 높이 56px 그대로)**: 나무 선반 느낌(조금 더 밝은 나무, 아래쪽 그림자).
   - 제목 "국어사전"은 금박 글씨(금색 그라디언트 글자와 약한 음각 그림자).
   - **놀이**·**도감** 단추는 제목 오른쪽에 붙여 묶는다. 크림색 종이 라벨에 작은 압정·나사 점 장식, 왼쪽에 단순한 SVG 아이콘(놀이: 게임 패드, 도감: 새싹).
   - 오른쪽 설정 묶음: 글씨 크기(Aa와 작은·중간·큰 점 세 개로 단계 표시), 소리(스피커), 전체 화면(네 모서리), 이 사전에 대하여(?)를 같은 종이 라벨 모양의 아이콘 단추로. 화면에서 글자를 줄이더라도 **접근 이름(`aria-label`)과 `title`은 지금 글자 그대로** 유지하고, 상태(`aria-pressed`)는 지금처럼 바뀌어야 한다. 소리 꺼짐은 아이콘으로도 구분되게(스피커에 사선).
   - 놀이 중 띠 가운데 **놀이 카드**는 메모지 모양(종이색, 아래쪽 살짝 들린 그림자). 찾을 낱말(빨리 찾기·한 번에 펼치기)은 지금보다 크게, 기본형 탐정 문장은 띠 높이 안에서 읽기 좋게.
4. **패널**(놀이 고르기·세트 고르기 `#gamePanel`, 도감 패널, 이 사전에 대하여 `#aboutPanel`): 줄 쳐진 색인 카드 종이(가로 연한 줄, 왼쪽 빨간 여백선은 선택), 위쪽 양 모서리에 반투명 마스킹테이프 두 조각, 살짝 기운 듯한 그림자.
   - 제목은 크게, 형광펜 밑줄(노란 띠) 느낌.
   - "놀이 고르기" 같은 돌아가기 단추는 둥근 라벨 모양.
   - 세트 단추는 작은 종이 카드(살짝 그림자, 누르면 눌린 모양). 기록이 있는 세트에는 **붉은 원형 도장**(지금 기록 문구는 도장 옆이나 아래 작은 글씨로 유지). 놀이 고르기의 놀이 세 개도 같은 카드 모양으로 크게, 놀이마다 작은 아이콘.
   - 도감 패널의 자음 칸 도장은 지금 붉은 도장 모양을 이 주제에 맞게 다듬는다.
5. **쪽지류**(`#wordNote`, `#gameNote` 피드백·결과 판, `#gameGuide`): 같은 종이 카드 계열로 통일(테이프 한 조각, 종이 질감). 결과 표는 줄 쳐진 장부처럼. "새 기록!"은 붉은 도장 모양.
6. **확대 창(`#hint`)**: 돋보기 느낌의 얇은 금속 테두리 정도로만.
7. 공통: 글씨는 지금 글꼴(Pretendard) 유지. 색은 CSS 변수로 모아 둔다(나무, 가죽, 종이, 금, 도장 빨강, 글자색).

## 바꾸지 않는 것
- 사전 지면(`.page`) 글자·조판, 옆면 캔버스(`#edges`) 그림과 색인 탭 색, 넘김(`#slab`, `.strip`), 무대 크기(1366×768)와 띠 높이(56px), `src/geometry.js`의 모든 수치와 판정.
- 놀이·도감의 동작과 문구(꾸밈을 위한 아이콘·도장 추가는 괜찮다). 기존 `id`와 접근성 속성은 유지(테스트와 코드가 쓴다).
- 성능: 크롬북(Lenovo 300e)에서 넘김이 느려지지 않게 `backdrop-filter`, 큰 `filter: blur`, 넘김 중 다시 그려지는 요소의 무거운 그림자를 쓰지 않는다. 바탕·표지 질감은 정적인 요소에만.
- `data/`, `기획서_v2.md`, `docs/` 수정 금지(시안 파일 포함). 새 의존성·외부 글꼴·외부 이미지 금지(아이콘은 인라인 SVG). 코드 주석 한국어. 띄운 프로세스는 끝날 때 모두 종료. **git 커밋·푸시 금지.**

## 완료 조건
- `npm test` 전부 통과.
- 브라우저(1366×768)에서 직접 보고 스크린샷을 `output/design-check/`에 남긴다: 기본 화면, 놀이 고르기, 세트 고르기(기록 있는 세트 포함), 놀이 카드 3종(빨리 찾기·한 번에 펼치기·기본형 탐정), 피드백 쪽지, 결과 판, 낱말 쪽지, 도감 패널, 이 사전에 대하여, 옆면 잡았을 때 확대 창, 넘기는 도중. 글자가 잘리거나 겹치는 곳이 없어야 한다. 콘솔 오류 없음. 시험 기록은 지운다.
- 넘김 중 프레임이 지금보다 눈에 띄게 떨어지지 않는지 `?debug`의 fps로 대략 비교해 보고 수치를 보고한다.
