# 작업 지시 12 — 낱말 도감

`기획서_v2.md` 6-0절(놀이 공통), 6-2c절(낱말 도감), 6-3절(보류한 "★ 낱말장에 담기")을 읽는다. 사전 본체, 낱말 쪽지(`#wordNote`), 놀이 세 개(`src/quickfind.js`, `src/openonce.js`, `src/baseform.js`, 묶음 `src/games.js`)가 동작한다. 여기에 **낱말 도감**을 더한다.

## 무엇을 모으나
- **★ 담기**: 평소 낱말 쪽지 위쪽(닫기 × 옆)에 ☆/★ 단추. 누르면 도감에 담고(★), 다시 누르면 뺀다(☆). 쪽지를 열 때 이미 담긴 낱말이면 ★로 보인다. 단추에는 `aria-pressed`와 "도감에 담기/도감에서 빼기" 이름을 붙인다.
- **놀이에서 찾은 낱말(자동)**:
  - 낱말 빨리 찾기: 정답 표제어를 터치해 찾은 문제(시간 초과는 제외).
  - 기본형 탐정: 정답 표제어를 터치해 찾은 문제("정답 보기"로 본 것은 제외).
  - 한 번에 펼치기: 거리 0으로 펼쳤거나, "넘겨서 확인하기"에서 정답을 터치한 문제.
  - 처음 담길 때만 그 놀이의 피드백 문구 끝에 짧게 "· 도감에 담았어요"를 붙인다(이미 있던 낱말이면 붙이지 않음).
- 같은 낱말은 한 번만 들어간다. 어디서 담겼는지(★/놀이 이름)는 처음 담긴 출처를 남긴다.

## 도감 화면
- 위쪽 띠 "놀이" 단추 옆에 **도감** 단추(`aria-expanded`, 패널 연결). 놀이 진행 중이거나 넘김·누르기 중에는 열지 않는다(다른 띠 단추와 같은 막기 규칙).
- 도감 패널(놀이 패널과 같은 자리·비슷한 크기, 책을 다 덮지 않음):
  - 제목 "낱말 도감 · ○개 모음".
  - **자음 14칸**(ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ, 색인 탭과 같은 색). 그 자음 낱말이 하나라도 있으면 칸에 **도장**(살짝 기울어진 붉은 원형 도장 모양, CSS로)이 찍히고 개수를 보여 준다. 없으면 흐린 빈칸.
  - 14칸이 모두 찍히면 "도감 완성!" 한 줄.
  - 칸을 누르면 아래에 그 자음 낱말 목록(가나다순, 출처 표시 ★/빨리 찾기/한 번에 펼치기/기본형 탐정). 낱말을 누르면 도감을 닫고 그 낱말이 있는 펼침을 열어 항목을 표시한 뒤 평소 낱말 쪽지를 연다(쪽지에서 ★로 바로 뺄 수 있게).
  - 맨 아래 **모두 지우기**(확인 창 뒤 삭제). 반에서 기기를 함께 쓰기 때문에 필요하다.
- 낱말의 자음 칸은 그 낱말 표제어의 첫 글자 초성으로 정한다(쌍자음은 예사소리 칸: ㄲ→ㄱ). 색인 구간(`index.sections`)과 같은 기준이어야 한다.

## 저장
- `localStorage` `dictionary-collection-v1`: `{ version: 1, words: { [id]: { w, hn, seq, from, at } } }`. `id`는 표제어 ID(어깨번호까지 구분), `from`은 `star|quickfind|openonce|baseform` 중 하나, `at`은 담은 시각(ms).
- 읽을 때 형식이 깨졌거나 값이 이상한 항목은 버리고 나머지를 살린다. 저장할 수 없는 브라우저면 도감 패널에 "이 브라우저에서는 도감을 저장할 수 없어요"를 보여 주고 앱은 계속 동작한다.
- 펼칠 때는 저장된 `seq`의 entries 묶음을 읽어 `id`가 맞는지 확인한다. 다르면(사전이 다시 만들어진 경우) 그 낱말을 목록에 둔 채 "낱말 자리를 찾지 못했어요"를 알린다.

## 구조
- 새 모듈 `src/collection.js`(저장·판정 순수 함수 + 패널 UI). `main.js`·놀이 모듈에는 연결 지점만 둔다. 놀이 모듈은 "찾았다"는 순간에 공통 콜백(예: `collect(entry, from)`)을 부르기만 한다. 콜백은 `createGames` 옵션으로 넘긴다.
- DOM과 무관한 것(초성 → 칸, 담기/빼기/중복, 저장 형식·손상값 복구, 완성 판정)은 `tests/`에 테스트.
- `?debug`에서 `window.__collection`(상태 보기) 정도.

## 지켜야 할 것

## 완료 조건
- `npm test` 전부 통과(새 테스트 포함). 데이터를 바꾸지 않으면 `build:data`는 다시 돌리지 않아도 된다.
- 브라우저(1366×768)에서 직접 확인: 낱말 쪽지 ★ 담기·빼기 → 도감 단추 → 자음 칸 도장·개수 → 칸 목록 → 낱말 누르면 그 펼침과 쪽지 → 놀이 세 개에서 정답 찾으면 자동으로 담기고 문구가 처음 한 번만 붙음(기본형 탐정 정답 보기, 빨리 찾기 시간 초과는 안 담김) → 새로 고침 후 유지 → 모두 지우기. 14칸 완성 문구(디버그로 채워서). 놀이 중 도감 단추 막힘. 콘솔 오류 없음. 시험 기록과 도감은 끝나고 지운다.
