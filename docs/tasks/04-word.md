# 작업 지시 04 — 낱말 터치, 뜻풀이 확대, 글씨 크기 전환, 메뉴

전체 기획은 `기획서_v2.md`(4-8절, 7장)를 읽는다. 책 본체는 이미 동작한다. 이 작업은 그 위에 네 가지를 얹는다.

## 현재 구조 (먼저 읽을 것)

- `index.html`, `src/style.css`, `src/main.js`, `src/geometry.js` — 프레임워크·번들러 없는 정적 사이트. 1366×768 무대를 통째로 확대·축소한다.
- `src/main.js`: 쪽 내용 그리기(`pageHtml`, `fill`), 옆면 캔버스(`drawEdges`), 넘김(`startFlip`/`setPhi`/`settle`), 입력(pointer 이벤트). 상태는 `L`(왼쪽 면 쪽 번호), `flip`, `press`.
- `src/geometry.js`: 터치 대상 판정 `hitTest` → `tab`/`bundle`/`page`/`none`.
- 데이터: `data/build/{normal|large|xlarge}/index.json`, `pages-NNNN.json`, `data/build/entries/entries-NNNN.json`. 스키마는 `data/build/README.md`.
- 실행: 프로젝트 폴더에서 `python -m http.server 8765` 후 `http://localhost:8765/`. `?debug`를 붙이면 판정 영역과 상태가 보이고 `window.__dict`로 상태를 읽을 수 있다. `?p=600`은 시작 쪽.

## 해야 할 일

### 1. 낱말 터치
- 지면에서 **움직이지 않고 짧게 터치**(이동 8px 미만)하면 그 자리의 표제어 항목을 선택한다. 끌면 지금처럼 넘김이다.
- 지면 가운데(`hitTest`가 `none`인 곳)뿐 아니라 한 장 넘김 영역(`page`)에서도, 끌지 않고 떼면 낱말 선택으로 처리한다. 옆면(`tab`/`bundle`)에서는 선택하지 않는다.
- 판정은 넉넉하게: 항목의 어느 줄을 눌러도 그 항목이 선택된다. 줄 사이 빈틈을 눌렀으면 세로로 가장 가까운 줄의 항목을 고른다(20px 이내).
- 이를 위해 `pageHtml`의 각 줄에 그 줄이 속한 표제어 순번(`data-e`)을 넣는다.
- 선택된 항목의 줄들은 지면에서 옅은 색으로 표시한다.

### 2. 뜻풀이 확대 쪽지
- 선택하면 **반대쪽 면 위에** 쪽지 모양의 작은 영역을 띄운다(왼쪽 면 낱말이면 오른쪽 면 위, 오른쪽 면 낱말이면 왼쪽 면 위). 읽던 자리를 가리지 않기 위해서다. 화면 전체를 덮는 팝업은 금지.
- 크기는 한 면 안쪽(폭 약 500px, 높이는 내용만큼, 최대 620px에서 넘치면 쪽지 안에서 스크롤).
- 내용은 `entries` 데이터에서 가져온다: 표제어(어깨번호), 품사, 권장 학년군(등급 1 "학교 가기 전", 2 "1~2학년", 3 "3~4학년", 4 "5~6학년"), 뜻 번호별 뜻풀이와 예문, 비슷한말·반대말. 본문보다 큰 글씨(뜻풀이 22px 안팎, 표제어 32px 안팎).
- 닫기: 쪽지의 닫기 버튼, 쪽지 밖을 터치, 또는 종이를 넘기기 시작할 때. 닫으면 지면의 표시도 지운다.
- 종이에 붙인 쪽지처럼 보이게(미색 바탕, 옅은 그림자, 살짝 기울임 정도). 과한 장식 금지.

### 3. 글씨 크기 전환
- 3단계(`normal` 16px, `large` 18px, `xlarge` 20px). 단계마다 데이터 폴더가 다르고 전체 쪽수·색인 범위도 다르다.
- 바꾸면 **보고 있던 표제어 기준으로** 위치를 복원한다: 현재 펼친 면에서 시작하는 첫 표제어의 순번을 기억했다가, 새 단계의 `index.entryPage[순번]`이 보이는 면을 펼친다.
- 선택한 단계는 `localStorage`에 저장해 다음 접속 때 유지한다.
- 지금 `main.js`는 `index`, `N`, `sections`를 한 번만 읽는 상수로 쓴다. 단계 전환이 되도록 고치되, 쪽 묶음 캐시가 단계 사이에 섞이지 않게 한다.

### 4. 메뉴
- 평소에는 **책등 위쪽에 걸린 작은 책갈피 끈 모양 버튼 하나**만 보인다. 상시 헤더·사이드바 금지.
- 누르면 그 아래로 작은 패널(폭 320px 이하)이 열린다. 항목:
  - 글씨 크기: 보통 / 크게 / 아주 크게
  - 전체 화면 켜기·끄기 (Fullscreen API)
  - 이 사전에 대하여: `data/build/ATTRIBUTION.md`의 요지(두 자료 이름, 제공 기관, 라이선스, 가공 내용)를 한글 몇 줄로 보여 준다.
- 패널 밖을 터치하면 닫힌다.

## 지켜야 할 것

- 넘김 동작(한 장, 묶음, 색인, 스냅, 휘어짐, 그림자)의 모양과 판정을 바꾸지 않는다. `src/geometry.js`의 판정 규칙과 상수는 그대로 둔다.
- 쪽지·메뉴 위에서 시작한 터치가 넘김으로 이어지면 안 된다. 반대로 쪽지·메뉴가 닫혀 있을 때 넘김 판정 영역을 가리면 안 된다(책갈피 버튼은 책등 위쪽의 좁은 자리만 차지).
- 넘기는 도중에는 낱말 선택과 메뉴 조작을 받지 않는다.
- 프레임워크, 번들러, 새 의존성 추가 금지. 순수 JS/CSS.
- `data/`, `scripts/`, `기획서_v2.md`, `docs/`는 수정하지 않는다.
- 뜻풀이·예문을 고쳐 쓰지 않는다. 데이터에 있는 그대로 보여 준다.
- 코드 주석은 한국어, 기존 코드의 방식(짧은 함수, 한 줄 이유 주석)을 따른다. 파일이 길어지면 `src/` 안에서 모듈로 나눠도 된다.
- git 커밋 금지.

## 완료 조건

- `npm test` 통과(기존 13개 유지). DOM에 의존하지 않는 새 로직(예: 글씨 단계 전환 때 펼칠 면 계산)이 있으면 `tests/`에 테스트를 추가한다.
- 브라우저에서 직접 확인:
  1. 지면의 낱말을 터치하면 반대쪽 면에 쪽지가 뜨고 그 항목이 지면에서 표시된다.
  2. 다른 낱말을 터치하면 쪽지가 바뀐다. 쪽지 밖 빈 곳을 터치하거나 넘기기 시작하면 닫힌다.
  3. 지면 가장자리를 끌면 여전히 넘어가고, 색인 탭과 옆면도 전과 같이 동작한다.
  4. 글씨 크기를 바꾸면 보던 낱말이 여전히 펼친 면에 있고, 옆면의 색인 위치와 전체 쪽수가 새 단계 값으로 바뀐다. 새로 고침해도 단계가 유지된다.
  5. 책갈피 버튼으로 메뉴를 열고 닫을 수 있고, 전체 화면 전환이 된다.
- 콘솔 오류가 없다.
